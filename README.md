# Chat

Chat em tempo real com Socket.io.

## Funcionalidades

- Sala **Geral** (todo mundo)
- Conversas **privadas** (clique em um usuário online)
- Lista de quem está **online** no menu lateral
- Nome salvo no navegador (localStorage)
- Notificações do navegador
- Responsivo (funciona no celular)

## Como rodar localmente

```bash
npm install
npm start
```

Abra: http://localhost:3000

## Deploy (Render, Railway, etc)

- Build: `npm install`
- Start: `npm start`
